## Reproduction Steps

These steps show how to reproduce the analysis.

They are catered to ``VS Code`` users, however, similar steps ought to apply for other IDEs.

Install Git (https://github.com/git-guides/install-git)

Install Docker (https://www.docker.com/get-started/)

Choose a parent directory to place the data and code in

Download the Algonauts 2025 Challenge data (https://drive.google.com/drive/folders/1y_AZ9Gvt9CwLbmmm8AhGR3GCxyQOeK7c)

---
**NOTE**

Press ``algonauts_2025_challenge_tutorial_data`` and then ``Download``

The zip file is big and will be split into 2 files upon downloading

---

Extract the data in the 2 files to the parent directory

---
**NOTE**

The final folder should be ~3.22 GB

---

Open a console window and navigate to the parent directory
``git clone https://github.com/brainhack-school2025/leclei_project``

Open ``VS Code`` or your favorite modern IDE

``File`` > ``Open Folder`` (``Ctrl+K Ctrl+O`` in ``VS Code``) > ``leclei_project``

Go to the extensions tab (``Ctrl+Shift+X`` in ``VS Code``) and install ``Dev Containers``

``Help`` > ``Show All Commands`` (``Ctrl+Shift+P`` in ``VS Code``) > ``Dev Containers: Rebuild Without Cache and Reopen in Container``

Open ``notebook.ipynb`` and run the cells (``Run All`` > ``Python Environments...`` > ``Python 3.12.3 /bin/python3``)

---
**NOTE**

The plots will be added in format ``_LETTER_PLOTNAME.EXTENSION``

The missing plots are screenshots taken from ``relevant_notebook/BHS_fMRI_connectivity.ipynb`` Cell 13 (``k``) and 16 (``l``);
and Cell 18 of ``notebook.ipynb`` when selecting scene ``Sorry.`` (Chunk number 129) (``n`` & ``o``)
